# aula-Scavolini

Strumenti d'aula per il corso "Il sistema di vendita" · Scavolini Academy.

- `nuvola/aula.html` — schermo del formatore (proiettore): crea la nuvola di parole, mostra QR e risultati.
- `nuvola/telefono.html?c=CODICE` — pagina che i partecipanti aprono dal QR.

I dati passano dalla funzione `nuvola` del progetto Supabase "Prove corsi": nessuna chiave nel browser.
